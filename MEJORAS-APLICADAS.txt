YERAL-Pro — MEJORAS DE ESTABILIDAD

Cambios en esta revisión:
- El analizador M3U ahora procesa línea por línea para reducir memoria temporal al cargar listas grandes.
- Compatibilidad mejorada con BOM, nombres que contienen comas, tvg-name, tvg-id, tvg-logo, group-title y #EXTGRP.
- Se descartan entradas M3U sin URL HTTP/HTTPS válida.
- Validación más estricta de direcciones de servidor y listas.
- Las cargas y actualizaciones M3U usan el helper con tiempo máximo de espera; ya no quedan peticiones de actualización sin timeout.
- Se evita iniciar varias actualizaciones simultáneas.
- Los errores de carga y actualización muestran más información útil.
- Se conserva el diseño y la funcionalidad previa de YERAL-Pro.

Pruebas realizadas:
- Sintaxis JavaScript (node --check): correcta.
- Sintaxis del script de compilación Bash: correcta.
- Sintaxis de patch_tv.py: correcta.
- Prueba M3U con BOM, atributos, EXTGRP, nombres con comas y URL inválida: correcta.
- Prueba de carga de 40.000 entradas M3U: correcta.
- Validación de URL http/https y host:puerto: correcta.

Nota de compilación:
Este paquete contiene el proyecto fuente actualizado. No incluye un APK nuevo; para generar la APK hay que ejecutar build-yeral.sh en un entorno con Node.js, Java, Android SDK y conexión a Internet.


Actualización visual — paleta unificada para ExoPlayer/Media3:
- Se alineó el color de acento del reproductor nativo con el tema violeta/cinema de index.html (#7028F5).
- Se actualizaron los estados de enfoque, botones, barra de progreso, EPG y menús del reproductor para usar tonos violeta coordinados.
- Se conservaron los colores semánticos (por ejemplo, EN VIVO y mensajes de estado) y el fondo negro de vídeo.
- El proyecto genera el código Android/ExoPlayer desde build-yeral.sh durante la compilación.


Reproductores de respaldo VLC y MPV (cadena de reproducción):
- ExoPlayer (Media3) sigue siendo el reproductor principal; el contenido que ya funciona no cambia.
- Si ExoPlayer agota sus reintentos (salvo HTTP 404), se abre AltPlayerActivity: primero VLC (LibVLC 3.7.6) y, si también falla, MPV (libmpv 1.0.0).
- También se puede elegir a mano en Opciones del reproductor: "Reproducir con VLC" / "Reproducir con MPV".
- Las librerías se llaman por reflexión: si alguna no está en la APK, ese reproductor se omite sin romper la app.
- minSdk sube a 26 (Android 8.0+, por libmpv). La APK se limita a arm64-v8a y armeabi-v7a.
- Si la compilación falla con VLC/MPV, el script reintenta sin ellos (queda solo ExoPlayer).
- Controles en VLC/MPV: OK pausa, izquierda/derecha ±10 s, arriba audio, abajo subtítulos, MENÚ aspecto.


Cambio de marca — GLYSTV PRO ahora es YERAL-Pro:
- Nombre de la app: YERAL-Pro (pantalla de inicio, título, cabecera, selección de perfil, recuadro «Salir de YERAL-Pro» y nombre bajo el icono en Android/TV).
- Nuevos identificadores: com.yeral.app (código) y com.yeral.pro (aplicación). Se instala como app nueva, aparte de GLYSTV.
- Icono nuevo (icono.png + yeral-res.zip con todos los mipmaps), banner de Android TV nuevo (banner.png) y emblema/favicon nuevos dentro de index.html.
- Script de compilación renombrado a build-yeral.sh (el flujo de GitHub Actions ya apunta a él).
- Se mantuvieron sin cambio dos valores internos: la clave que protege los PIN de los perfiles web y la dirección web usada para el código QR.


Celular Android, Google TV y TV box (esta revisión):
- Se quitó todo lo de iPhone: ios.yml, @capacitor/ios y el bloque iOS de build-yeral.sh.
- El manifest ya no obliga a Google TV: leanback y pantalla táctil son opcionales (required=false), así la APK se instala en celulares Android, Google TV y TV box.
- Se mantienen el icono de launcher (celular) y el LEANBACK_LAUNCHER + banner (TV).
- Nuevo estilo en index.html (bloque "estilo streaming" al final del CSS): cabecera transparente tipo Netflix, filas horizontales con carátulas 2:3, mosaicos oscuros con brillo tipo Disney+, botones y categorías en píldora tipo XuperTV, canales en vivo con barra de color y etiqueta EN VIVO tipo Flujo TV.
- Celular en vertical: menú en 2 columnas y botones de 44 px. Pantallas grandes (TV): letras, carátulas y marco de foco más grandes para el control remoto.
- No cambió la lógica de la app (login, listas, reproductores).
- No se pudo compilar aquí (sin Internet): compilar con GitHub Actions (build.yml) y probar en celular y TV.
